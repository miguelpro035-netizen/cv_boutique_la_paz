# Entrega revisada — tres catálogos web

Este ZIP contiene tres proyectos independientes:

1. `1_BARBERIA_FILO_REAL`
2. `2_PERFUMERIA_MAISON_ILLIMANI`
3. `3_LICORERIA_BRINDIS_3600`

Se conservaron los diseños y funcionalidades existentes. La revisión incorporó una imagen de apariencia fotográfica en la portada de Filo Real y comprobaciones técnicas de rutas, JSON, JavaScript y precarga offline.

Lee `REVISION_FINAL.md` antes de presentar los catálogos. Ahí se indican las mejoras y los datos/imágenes que todavía deben confirmarse con cada cliente.

Para ejecutar cualquiera de los proyectos, entra en su carpeta y ejecuta `python -m http.server 8000`; luego abre `http://localhost:8000/`.
